As evidências

As Evidências da Audiência

Se @Test é a audiência, as asserções são as evidências apresentadas ao juiz. E o padrão AAA é o roteiro que todo bom advogado segue: organizar o caso, provocar o evento, e só então apresentar as evidências.

Ferramentas do julgamento

A família de asserções do JUnit 5

Clique em cada asserção para ver o que ela verifica.

assertEquals
assertTrue/False
assertNull/NotNull
assertThrows
assertAll
O roteiro

Padrão AAA — Arrange, Act, Assert

@Test
void depositoDeveAumentarSaldo() {
    // Arrange: organiza o caso
    ContaBancaria conta = new ContaBancaria("Maria", "123");

    // Act: provoca o evento julgado
    conta.depositar(100.0);

    // Assert: apresenta a evidência
    assertEquals(100.0, conta.getSaldo());
}
Exemplo

Testando exceções com assertThrows

IllegalArgumentException excecao = assertThrows(
    IllegalArgumentException.class,
    () -> conta.sacar(100.0)
);

assertEquals("Saldo insuficiente...", excecao.getMessage());

O código dentro da lambda é a "ação" — o JUnit confirma que a exceção certa foi lançada.

Exemplo

Agrupando com assertAll

assertAll(
    () -> assertEquals("João", conta.getTitular()),
    () -> assertEquals("99999-9", conta.getNumeroConta()),
    () -> assertEquals(0.0, conta.getSaldo())
);

Roda TODAS as verificações, mesmo que uma falhe — mostrando todos os erros de uma vez.

Boas práticas

Nome de teste vago vs. descritivo

✗ VAGO

  • teste1()
  • testSaque()
  • Não diz o cenário nem o resultado esperado

✓ DESCRITIVO

  • sacarValorMaiorQueSaldoDeveLancarExcecao()
  • Conta uma pequena história: o quê + em que condição + o que se espera
