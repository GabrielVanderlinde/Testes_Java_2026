## 📂 Estrutura do Projeto

```

├── docs/                    # Documentação geral do curso
│   ├── README.md           # Plano de ensino completo
│   └── index.html          # Versão HTML do plano de ensino
├── aulas/                   # Conteúdo de cada aula
│   ├── aula-01/            # Fundamentos de Teste + Revisão de POO
│   ├── aula-02/            # Ambiente de Desenvolvimento
│   ├── aula-03/            # Primeiros Testes com JUnit 5
│   ├── aula-04/            # Asserções
│   ├── aula-05/            # Testes Parametrizados
│   ├── aula-06/            # Organização de Testes
│   ├── aula-07/            # Test Doubles
│   ├── aula-08/            # Mockito I
│   ├── aula-09/            # Mockito II
│   ├── aula-10/            # Cobertura de Código
│   ├── aula-11/            # TDD
│   ├── aula-12/            # Spring + Testes de Serviço
│   ├── aula-13/            # Testes de Repositório
│   ├── aula-14/            # Testes de Controller
│   └── aula-15/            # Projeto Integrador
├── exercicios/              # Centro de exercícios global
│   ├── index.html          # Índice visual de todos os exercícios
│   ├── README.md           # Guia de exercícios
│   ├── aula-01/            # Desafios e gabaritos da aula 01
│   ├── aula-02/            # Desafios e gabaritos da aula 02
│   └── ...                 # (aula-03 até aula-15)
├── src/                     # Código Java e testes implementados
│   ├── main/
│   │   └── java/
│   │       └── exercicios/  # Classes de exercícios Java
│   │           ├── aula01/  # Aula 1: ContaBancaria, Livro
│   │           ├── aula03/  # Aula 3: Cliente, Pedido
│   │           ├── aula04/  # Aula 4: Exercícios e desafios

│   └── test/
│       └── java/

│               ├── aula01/  # Testes da aula 1
│               ├── aula03/  # Testes da aula 3
│               ├── aula04/  # Testes da aula 4
│               └── aula05/  # Testes da aula 5

└── .gitignore              # Arquivos ignorados pelo Git
```

## 🎯 Informações do Curso

- **Carga horária:** 60 horas
- **Número de aulas:** 15 aulas de 4 horas
- **Ferramentas:** IntelliJ IDEA, Java, Maven, JUnit 5, Mockito, Spring Boot
- **Pré-requisitos:** Lógica de Programação e POO (com reforço durante o curso)
