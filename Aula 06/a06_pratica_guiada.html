UC Teste de Sistemas · Aula 06 — Prática Guiada Testando uma hierarquia com @Nested

Prática guiada — testando a hierarquia Animal

Siga os passos abaixo para revisar herança/polimorfismo e organizar os testes com @Nested e @DisplayName.

1
Criar a superclasse abstrata Animal
▶

Crie a classe abstrata Animal, com o método abstrato emitirSom() (retorna String).

public abstract class Animal {
    protected String nome;

    public Animal(String nome) { this.nome = nome; }

    public abstract String emitirSom();
}
Uma classe abstrata não pode ser instanciada diretamente com "new Animal(...)" — só suas subclasses concretas podem.
2
Criar as subclasses Cachorro e Gato
▶

Cada subclasse implementa emitirSom() com seu próprio comportamento.

public class Cachorro extends Animal {
    public Cachorro(String nome) { super(nome); }
    @Override
    public String emitirSom() { return "Au au!"; }
}

public class Gato extends Animal {
    public Gato(String nome) { super(nome); }
    @Override
    public String emitirSom() { return "Miau!"; }
}
"super(nome)" chama o construtor da superclasse Animal, reaproveitando a lógica de inicialização do nome.
3
Criar a classe de teste com @Nested para Cachorro
▶

Crie AnimalTest com um grupo @Nested para os testes de Cachorro.

class AnimalTest {

    @Nested
    @DisplayName("Testes de Cachorro")
    class TestesCachorro {
        @Test
        @DisplayName("Deve emitir 'Au au!'")
        void emitirSomDeveSerLatido() {
            assertEquals("Au au!", new Cachorro("Rex").emitirSom());
        }
    }
}
Repare que @Nested é aplicado à CLASSE interna, e @DisplayName pode ser usado tanto nela quanto em cada @Test.
4
Repetir a estrutura para Gato
▶

Crie o segundo grupo @Nested, testando o comportamento de Gato.

    @Nested
    @DisplayName("Testes de Gato")
    class TestesGato {
        @Test
        @DisplayName("Deve emitir 'Miau!'")
        void emitirSomDeveSerMiado() {
            assertEquals("Miau!", new Gato("Whiskers").emitirSom());
        }
    }
Cada grupo @Nested é independente — você pode ter quantos precisar dentro da mesma classe de teste.
5
Adicionar @Tag e executar
▶

Marque o grupo de Gato com @Tag("felinos") e rode a classe inteira, observando a árvore de testes no IntelliJ.

AnimalTest
 ├─ Testes de Cachorro
 │   └─ ✓ Deve emitir 'Au au!'
 └─ Testes de Gato  [felinos]
     └─ ✓ Deve emitir 'Miau!'
No IntelliJ, a aba de execução mostra essa estrutura em árvore, exatamente como organizamos com @Nested.
